# Domain Glossary

## Purpose

Shared terminology used across product, mobile, and backend documentation.

| Term | Meaning |
|---|---|
| Customer | Merchant/mechanic requesting delivery |
| Driver | Motorcycle delivery operator |
| Admin / Operations | Privileged operational user |
| Order | A request to move a package from pickup to drop-off |
| Delivery Mode | Standard or VIP |
| Service Zone | Geographic/operational area with pricing and rules |
| Dispatch Offer | Temporary offer of an order to a driver |
| Active Order | Order currently accepted/in execution |
| Capacity Profile | Driver's allowed weight/volume/order limits |
| Route Compatibility | Whether another order can be added without violating constraints |
| Tracking Point | Timestamped driver location sample |
| Freshness | Classification of how recent/reliable a location sample is |
| Price Snapshot | Immutable price components stored on order confirmation |
| Rating | 1–5 score associated with an eligible completed order |
| Complaint | Customer feedback requiring operational attention |
| Ledger Entry | Immutable financial movement |
| Admin Alert | Operational notification requiring attention |
| ADR | Architecture Decision Record |

Additional domain classifications: [`../backend/DOMAIN_MODEL.md`](../backend/DOMAIN_MODEL.md).
