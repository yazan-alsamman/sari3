# Mobile Design System

## UX principles

- Fast task completion.
- Clear operational status.
- Large touch targets for drivers.
- Strong distinction between Standard and VIP.
- Human-readable Arabic-first content with RTL support.
- English localization-ready architecture.
- Accessible contrast and typography.
- Consistent loading/error/empty states.

## Driver safety

The app must minimize interaction while the driver is moving.

Navigation should prioritize glanceable information and defer non-essential actions.
